# Как добавить или изменить материал

Всё делается прямо на github.com — программист не нужен. После сохранения (Commit) сайт
обновляется сам за 1–2 минуты. Если в файле ошибка, сайт не сломается: во вкладке **Actions**
будет красный крестик и текст ошибки, а сотрудники увидят прежнюю версию.

## Карточка меню — папка `menu/`
Add file → Create new file → имя латиницей без пробелов, например `syrniki.md`:

```
---
название: Сырники со сметаной
категория: Завтраки
проекты: Лицей, Т-Банк          ← пусто = во всех проектах
должности: Официант, Бариста     ← пусто = всем
аллергены: молоко, яйца, глютен
фото: syrniki.jpg               ← файл в папке img/
выход: 220 г
кратко: одна строка под названием
порядок: 1                      ← чем меньше, тем выше в списке
---
**Состав:** …
```
Фото: открыть папку `img/` → Add file → Upload files.

## Материал или чек-лист — папка `materials/`
Шапка: `название`, `раздел`, `должности`, `проекты`, `кратко`, `порядок`.
Пункты вида `- [ ] Сделать то-то` превращают материал в чек-лист — сотрудник отмечает их в приложении.
`звёзды: 5` — сколько звёзд дать за полностью выполненный чек-лист.

Можно: заголовки `## …`, **жирный**, списки, таблицы, фото `![](img/файл.jpg)`, цитата-подсказка `> …`,
ссылка на другой материал `[[имя-файла]]`.

## Программа обучения — папка `programs/`
`## День 1` и шаги списком:
- `[[имя-файла]]` — материал, чек-лист или карточка меню
- `тест: T01` — тест из Google-таблицы (засчитывается, когда сдан)
- любой текст — сотрудник отмечает сам

`звёзды: 50` — за всю пройденную программу.

## Уведомления
Новый файл → бот пишет тем, кому он подходит по должности и проекту. Изменение — «обновлено».
Если правка мелкая (опечатка) и писать не нужно, добавьте в шапку `уведомлять: нет`.
Скрыть материал, не удаляя: `скрыть: да`.
